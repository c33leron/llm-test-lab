# Changelog

## 0.1.0-alpha.1 — 2026-11-06

First technical alpha; Python package version `0.1.0a1`. The browser provides the teaching mission, while experiment configuration and live-model profiles remain CLI workflows. This is not a stable release or a validated live-model benchmark.

- Active, Russian-language local browser mission through `./lab start`: prediction, evidence selection, a four-part access policy, actual checks, changed-user transfer, reflection and JSON experiment-card export.
- Five dedicated learning cases, L01–L05. The mission preserves useful work as well as the access boundary; scripted execution is never presented as model evaluation.
- Saved lesson progress, explicit experiment actions, cancellation and fixture-only managed child processes. Opening or reloading the screen does not run a trial.
- The earlier terminal menu remains available through `./lab start --terminal`; `--case` and advanced CLI workflows are preserved. `--web --no-open` is the explicit unattended local-screen route.
- Project-local, pinned dependency setup; no model download or cloud calls.
- Human-readable HTML results before expandable raw evidence, actual field changes, and expected-fixture outcome explanation.
- Short terminal results with explicit machine-readable `--json` output.
- Installed-source identity checks: a copied checkout cannot approve one source tree while executing another through a shared venv.
- Oracle 1.0.1 checks full independent readback against allowed mutations and committed transitions, not only the audit's changed-fields summary.
- Bounded HTTP response reading, explicit modern/legacy Chat Completions output-token parameter, and validated generation settings.
- Evidence-bound support claims for profiles. A limited compatibility probe does not certify live support.

Live reference coverage and real first-use observations are not claimed complete. See release readiness for the final evidence and blockers.

The dated pre-publication validation records 357 passing pytest tests on macOS arm64 and 357 on Linux/amd64 in Docker on an ARM host, plus 9/9 smoke and 36/36 core fixture attempts on each platform. The browser journey and evidence export were also exercised. These are lab checks, not model-quality scores or independent novice acceptance.

The new loopback-only lesson screen does not enable the separately disabled Promptfoo viewer. Earlier test totals and terminal-route acceptance are not automatically evidence for this new interface.

See [release notes](docs/releases/v0.1.0-alpha.1.md) for the user-facing scope and limitations.

## Initial technical preview — 2026-11-03

- Twelve core cases, two forced controls, three protection variants, strict contracts, SQLite tools, independent oracles, evidence and Promptfoo bridge.
- 159 local tests and a 36-cell fixture matrix were observed at that source snapshot.
- No public release was published; no live-model reference matrix was run.

# Границы безопасности

Противник в сценарии управляет запросом или заметкой в заявке, но не планом, исходной базой, проверками, файлами результатов или ключом модели. Личность пользователя задаёт приложение. Лаба не защищает от владельца компьютера и вредоносного Python-кода в зависимостях.

Внутри опыта:

- Все записи синтетические. Маркер в B-201 помогает обнаружить утечку; это не настоящий ключ
- Инструменты не исполняют shell, произвольный SQL или пути из ответа модели и не обращаются в сеть
- В `vulnerable` и `prompt_only` отключена только проверка владельца. Схемы, транзакции, revision, commandId и лимиты остаются
- `enforced` защищает эту границу доступа, а не гарантирует безопасность любого приложения

## Локальный веб

Учебный сервер слушает только `127.0.0.1`. Стартовая ссылка содержит случайный ключ доступа, который затем убирается из адресной строки. Не публикуй ссылку и не открывай сервер наружу через прокси или туннель. API проверяет ключ и Host, а для изменений — также Origin; внешним сайтам CORS-доступ не предоставляется.

Веб разрешает только пять учебных сценариев без модели и четыре заранее определённых поля правила. Браузер не выставляет результат сам. Повтор с устаревшей revision отклоняется, прерванный опыт не продолжается автоматически. Перед завершением и экспортом сервер перепроверяет сохранённые доказательства. Объяснение ученика входит в экспорт — не записывай туда секреты.

## Подключение модели

Для облака требуется HTTPS, для Ollama — локальный HTTP-адрес. Транспорт проверяет TLS, ограничивает размер ответа, не делает скрытых повторов, redirects или proxy/env lookup. Локальный адрес Ollama сам по себе не доказывает отсутствие обращений daemon в облако: это нужно проверить отдельно. Настройки и ограничения — в [live-маршруте](live.md).

CLI передаёт worker минимальное окружение и не загружает `.env` автоматически. Выбранный ключ всё равно доступен транспортному worker: это не изоляция секрета от доверенного кода.

Отдельный viewer Promptfoo отключён: закреплённая версия не обеспечивает нужную привязку к loopback. Доступны локальные HTML/Markdown-отчёты; они экранируют текст и не загружают внешние ресурсы.

# Threat model и границы

Противник контролирует пользовательский запрос или note в разрешённом объекте. Он не контролирует trusted driver, principal, fixture seed, план, oracle, файлы evidence и ключ провайдера. Лаба не является sandbox против владельца компьютера или вредоносного Python-кода в зависимостях.

Все данные синтетические. B-201 содержит canary для доказательства происхождения раскрытых данных, не настоящий credential. Не подключай рабочие БД, документы работодателя и чужие аккаунты. Tools не используют сеть, shell, произвольные пути и SQL из ответов модели. Профиль задаёт оператор, не недоверенный текст. Не подключай сторонние Python assertions, не прочитав их код.

В vulnerable/prompt_only отключена только owner ACL внутри изолированного attempt. Strict schemas, параметризованный SQL, транзакции, optimistic concurrency, commandId и бюджеты сохраняются. Enforced защищает эту конкретную границу владельцев, но не гарантирует правильность любой собственной правки или ответа.

HTTPX отключает retries, redirects и proxy/env lookup; TLS verification включена. Cloud endpoint требует HTTPS, Ollama — loopback. Это не сертификат конфиденциальности Ollama: daemon может проксировать запрос облачной модели. Shipped local profile остаётся experimental до отдельного доказательства artifact/digest, daemon-local-only и отсутствия upstream egress.

CLI передаёт subprocess минимальное окружение, использует чистый cwd и не подхватывает чужие `.env`/DOTENV_* настройки. Явно выбранный credential нужен транспортному worker; он не превращает worker в изолированный от ключа sandbox. Не передавай ключ как аргумент команды. Если настоящий секрет всё-таки раскрыт, его нужно ротировать, а не только отредактировать лог.

Promptfoo 0.125.1 viewer в исследованной версии слушает все интерфейсы и не предоставляет поддержанного host-флага. `lab view` **не запускает его**. Используй статические локальные report.md/report.html. Это явное незакрытое требование исходного ТЗ, не скрытая замена полноценной viewer-приёмки. Отчёты экранируют недоверенные строки и не подгружают изображения из модели.

## Локальная учебная страница

`./lab start` запускает отдельный маленький HTTP-интерфейс только на `127.0.0.1`, не viewer Promptfoo. Случайный ключ доступа находится во фрагменте стартовой ссылки, затем очищается из адресной строки. Он не является ключом модели; не публикуй ссылку и не выставляй сервер наружу через прокси или туннель. Для API нужны этот ключ и точный Host; изменения также требуют точный Origin. У страницы нет CORS-доступа, внешних скриптов, произвольных file/run endpoints или выбора облачного профиля.

Сервер разрешает только пять учебных fixtures с нулевым бюджетом inference. Политика доступа — четыре значения из конечного списка, не Python-код. Неправильные варианты намеренно позволяют проверить недоверенную личность из note, неполный охват действий и слишком поздний контроль. Доверенный principal не меняется. Последствия ограничены отдельной синтетической базой каждого опыта.

Переходы урока и результаты оцениваются сервером. Повторный запрос с устаревшей revision не создаёт новый опыт; сброс сохраняет старую сессию. Прерванный опыт не продолжается сам. Завершение и экспорт повторно проверяют сохранённые bundles; JSON-карточка не заменяет полный архив доказательств. Объяснение ученика сохраняется локально и входит в экспорт: не вводи в него секреты или персональные данные.

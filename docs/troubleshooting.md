# Если что-то не работает

Начни с `./lab doctor`: он проверяет установку, не обращаясь к модели. Команды нужно выполнять из папки проекта.

| Что видишь | Что сделать |
|---|---|
| `Permission denied` у `./lab` | Выполни `chmod +x lab` и повтори |
| `DEPENDENCY_MISSING` / `ENVIRONMENT_MISMATCH` | Повтори `./lab setup`. Не подменяй закреплённые инструменты глобальным `npx latest` |
| Браузер не открылся | Открой полный адрес из терминала. Без интерактивного терминала используй `./lab start --web --no-open` |
| После перезапуска страница не подключается | Открой **новую** ссылку запуска: адрес и локальный ключ могли измениться |
| `CASE_INVALID` / `INVALID_*` | Запусти `./lab validate`, проверь типы, лишние поля и IDs сценария |
| `FIXTURE_STEP_MISMATCH` | Сравни script и события: порядок ходов или ожидаемый ответ инструмента не совпал |
| `BUDGET_EXCEEDED` | Уменьши матрицу или создай новый план с явно выбранным лимитом |
| `MODEL_MISSING` | Укажи точный ID модели через переменную `modelEnv` выбранного профиля |
| `AUTH_FAILED` / `RATE_LIMITED` | Остановись и проверь endpoint, ключ и лимиты провайдера. Не добавляй бесконечные повторы |
| `CONTEXT_LIMIT` | Уменьши сценарий или выбери проверенный профиль с большим контекстом |
| `model_error` | Посмотри исходный ответ, причину остановки и формат tool calls/final JSON |
| `EVIDENCE_INVALID` | Найди отсутствующий или изменённый файл. Не переписывай хеши ради зелёного результата |
| `CAPABILITY_UNSUPPORTED` у `view` | Viewer Promptfoo отключён. Открой сохранённый `report.html` |

Отмена не откатывает уже сохранённые изменения. Сначала разбери имеющиеся материалы, потом решай, нужен ли новый запуск. Частичный отчёт — не успешная проверка; удаление `runs/` не чинит причину.

Если нужна помощь, приложи код ошибки, версии, case/variant/source и ID запуска. Фрагмент отчёта очисти от секретов и личных данных. Не прикладывай `.env`, ключи или всё окружение целиком.

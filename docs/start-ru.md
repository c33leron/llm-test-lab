# Быстрый старт

В браузере — учебная миссия без нейросети. Через терминал можно запускать отдельные проверки и [подключить модель](live.md). Проходить урок перед этим не обязательно.

## Установить и открыть

Скачай **Code → Download ZIP** на GitHub и распакуй архив. Открой терминал в этой папке. На Mac можно набрать `cd ` с пробелом, перетащить папку из Finder и нажать Enter.

Нужны macOS или Linux и [Python 3.10+](https://www.python.org/downloads/). Затем:

```sh
./lab setup
./lab start
```

`setup` скачивает инструменты и зависимости в папку проекта. Нужен интернет, но модели, API-ключи и платные запросы здесь не используются. Дождись успешной установки, затем запускай `start`. При `Permission denied` сначала выполни `chmod +x lab`.

`start` откроет страницу «Первое расследование». **Оставь терминал работающим** — он обслуживает страницу. В следующий раз достаточно `./lab start`, заново устанавливать всё не нужно.

Если браузер не открылся, перейди по полному адресу из терминала. После перезапуска используй новый адрес. Часть после `#` даёт доступ к локальному уроку: не публикуй ссылку и не открывай сервер наружу.

Для запуска без автоматического открытия браузера, в том числе из неинтерактивного терминала:

```sh
./lab start --web --no-open
```

## Пройти миссию

Ты — пользователь A. Помощника просят закрыть твою заявку A-101, но он попробует прочитать и чужую B-201. Его действия заданы сценарием; инструменты, база и проверка доступа выполняются заново. Это проверка защиты приложения, не качества нейросети.

1. **Предположи результат** и запусти опыт. Ошибочный прогноз не мешает пройти урок
2. **Найди доказательство** выдачи чужих данных. Попытка вызвать инструмент ещё не доказывает, что он что-то вернул
3. **Собери правило**: откуда брать личность пользователя, кому разрешать доступ, какие действия проверять и когда
4. **Запусти четыре проверки**: чужое чтение, обычная задача, безвредная цитата и чужая запись — L01, L02, L03 и L05. Запретить всё недостаточно: своя задача должна работать
5. **Смени роль**: теперь B-201 твоя, а A-101 чужая. В L04 проверяется то же правило, не новый ответ под другой номер
6. **Запиши вывод и скачай эксперимент**. Для объяснения достаточно 20–2000 символов. Получишь JSON с прогнозом, выбранным событием, правилом и результатами. Это заметка для самопроверки: автоматически её смысл не оценивается

## Остановиться и продолжить

Обновление страницы сохраняет шаг и не запускает опыт повторно. **Ctrl+C в терминале** останавливает сервер и отменяет активный запуск; уже совершённые действия остаются в материалах.

Чтобы вернуться, снова выполни `./lab start`. Прерванный опыт сам не продолжится — его нужно повторить кнопкой. «Начать заново» создаёт новый урок, сохраняя старый. Полные материалы лежат в `runs/`, прогресс — в `.lab-state/learning/`; скачанная JSON-карточка не содержит все базы. Не вводи в объяснение секреты и личные данные.

# v0.1.0-alpha.1

First public alpha of LLM Test Lab. Package version: `0.1.0a1`.

## What's here

- A browser lesson: predict an outcome, find a data leak, build an access rule and check it with another user
- Five learning cases, 12 core CLI scenarios and two controls
- Real SQLite tool effects, independent checks and saved evidence
- Progress saving, cancellation and JSON export
- Experimental Ollama and Chat Completions-compatible connections through the CLI

The browser lesson needs no model or key. Live experiments use this lab's ticket agent; this isn't a scanner for arbitrary AI apps. Live-model support hasn't been validated with a real reference model yet.

## Start

Download the ZIP, extract it and open a terminal in the project folder:

```sh
./lab setup
./lab start
```

You'll need macOS or Linux, Python 3.10+ and internet access for setup. Keep the terminal open while using the lesson. Setup doesn't download models or make paid model requests.

[Release CI passed on Ubuntu and macOS](https://github.com/c33leron/llm-test-lab/actions/runs/42271995045): 357 tests per platform, 9 smoke and 36 core fixture attempts. These are lab checks, not model safety scores. Independent novice testing and native Windows support are not included.
